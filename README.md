# GitHub README Pixel Art

An open pixel canvas that ANYONE can paint on.
**Click any pixel**, pick a colour and submit the issue. The canvas updates in about a minute.

#### How it works

Each pixel links to a new issue with its coordinate in the title and a colour dropdown. When you submit it, a GitHub action runs a small Python script that paints the pixel, updates this README and commits the change.
