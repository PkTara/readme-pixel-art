#### How it works

This was built upon the work of [marcizhu](https://github.com/marcizhu/readme-chess/), who has a board where people can play chess on instead! 

When you click on a link and submit a new issue with the desired move, a GitHub action is triggered, which in turn runs a small python script that performs the specified movement, updates this README file and commits the changes.

Have you spotted a bug? Something missing? Feel free to open an [issue](https://github.com/PkTara/readme-pixel-art/issues) and I will try to fix it as soon as possible :D
